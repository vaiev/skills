# SideComputer skills

Playbooks for a remote always-on host that bots use as a second computer. The kit they drive is at https://github.com/vaiev/mcp/tree/main/sidecomputer. Fetch it with `git clone https://github.com/vaiev/mcp`, then use the `sidecomputer/` directory.

Use these paths when another repository links here.

| Skill | Path in this repository | Canonical path |
| --- | --- | --- |
| sidecomputer-getting-started | `sidecomputer/getting-started/SKILL.md` | `vaiev/skills/sidecomputer/getting-started/SKILL.md` |
| sidecomputer-dispatch | `sidecomputer/dispatch/SKILL.md` | `vaiev/skills/sidecomputer/dispatch/SKILL.md` |
| sidecomputer-admin | `sidecomputer/admin/SKILL.md` | `vaiev/skills/sidecomputer/admin/SKILL.md` |

The dispatch playbook is `vaiev/skills/sidecomputer/dispatch/SKILL.md`.
